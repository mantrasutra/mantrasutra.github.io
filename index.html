सूत्र

सूत्र is a compact string notation for closed-form functions, with a two-way map: a string gives a function, and a function in a supported form gives its canonical string. The map is between strings and a countable term algebra, not all analytic functions. Unsupported or malformed input gets a named refusal, never a guess.

Everything runs in your browser on the same Python engine the project tests against. First load downloads about 25 MB; after that the site makes no other network request.

  • Editor
    Write a string or a formula; see the parsed term and its value.
  • Functions
    Domain packs of textbook formulas, as strings.
  • Explorer
    Surfaces and curves of functions.
  • Mantra
    Verse analysis: text, prosody, structure.

Page names and pack titles are English placeholders until the owner rules the Devanagari names. Read About for what is and is not claimed.
